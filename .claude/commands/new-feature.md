Guide the user through the feature workflow for this Expo mobile app:
1. Propose a plan in bullets and wait for approval.
2. Create/update types in `lib/types.ts` or feature-specific type files if needed.
3. Create/update Zustand store in `lib/stores/` if needed.
4. Create/update hooks in `lib/hooks/` if needed.
5. Create/update UI components in `components/`.
6. Compose in the appropriate screen under `app/`.
7. Write Vitest unit tests in `__tests__/`.
8. Run `npm test` to verify.
